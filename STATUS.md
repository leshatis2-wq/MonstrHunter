# Статус прототипа — 14 сентября 2026

## Подготовлено

- Swift-исходники охоты, геометрического AR-размещения, прицеливания и ловли.
- Локальное сохранение пойманных монстров для будущего зоопарка.
- Временная оригинальная 3D-модель Мохлика из примитивов; это не модель Blender.
- Готовый Xcode-проект и общая схема приложения/тестов.
- Ручной GitHub Actions workflow для сборки без подписи и XCTest.

## Проверено здесь

- Python-генератор проекта исполняется на Windows.
- Info.plist корректно читается стандартным plist-парсером; указано разрешение камеры и требование ARKit.
- XML схемы читается; тестовая цель включена.
- Все шесть Swift-файлов перечислены в сгенерированном проекте.

## Ещё не проверено

- Компиляция Swift / открытие проекта в Xcode.
- Выполнение XCTest (тесты написаны, но здесь отсутствует Swift/Xcode).
- Реальная работа камеры, размещение, производительность и ловля на iPhone.
- Сборка с подписью, TestFlight, App Store.

## Что требуется дальше

1. Войти в GitHub во встроенном браузере для создания отдельного приватного репозитория. Подключённый GitHub-коннектор уже видит аккаунт LeshaTIs; браузерный вход отдельный.
2. Загрузить проект и проверить доступный лимит macOS Actions перед запуском.
3. Запустить сборку и исправить возможные ошибки компиляции по настоящему журналу Xcode.
4. Для установки через TestFlight — подключить Apple Developer и настроить подпись. Ничего платного пока не подключалось.

Исходники готовы к следующему этапу, но работа приложения на устройстве пока не подтверждена.
